# Khayal.flutter

مستودع تطبيقي **خيال** (`games_app`) و**Game Control** (`control_app`) مع سير عمل البناء.

**كل التوثيق في ملف واحد:** [`docs/GUIDE.md`](docs/GUIDE.md) — البناء، الإصدارات، الأسرار، الإعلانات، النشر، التطبيقان، خط الاستيراد، وخارطة المستقبل.

**ما يُبنى:** يحدده السطر الأول من `BUILD_TARGET.txt`: `1` = خيال، `2` = المتحكم، `12` أو `21` = الاثنان، وأي شيء آخر = لا يبني شيئاً (ما بعد `//` أو `#` تعليق).
